# Публичного экземпляра нет

У TelegramMe нет публичного экземпляра, и его не будет. Запускайте сервис на
своём сервере или на своём компьютере: это один контейнер.

Демо, которое работало на `tme.koval-dev.org`, отключено навсегда в ноябре
2026 года вместе с серверами и пайплайном развёртывания. По этому адресу API
больше не отвечает, и замены не будет.

## Почему { #why }

Демо было нужно, чтобы показать, что умеет проект, а не чтобы обслуживать
чужие приложения. Использовали его именно для этого:

- **На нём строили приложения.** Вместо того чтобы поднять свой экземпляр или
  встроить TelegramMe в свой продукт, его направляли в демо и пользовались им
  как бесплатным API. Проект открыт, чтобы его мог запустить каждый, а не
  чтобы один человек запускал его для всех.
- **Чужой трафик — ответственность мейнтейнера.** Каждый запрос шёл в t.me с
  серверов демо. Без возможности понять, кто и зачем его отправляет, демо
  рано или поздно могло начать обслуживать злоупотребления или криминал.
  Нести за это ответственность мейнтейнер не хочет.
- **Защита существовала только из-за злоупотреблений.** Лимиты запросов,
  защита от ботов и правила на edge держали демо на плаву и всё равно не
  мешали использовать его как бэкенд.

## Что делать вместо этого { #what-to-do-instead }

**Запустите свой экземпляр.** Образ публичный, и ему не нужны ни аккаунт, ни
ключ, ни токен:

```bash
docker run -d --name telegram-me -p 8000:3000 --restart unless-stopped \
  ghcr.io/koval01/telegram-me:latest
curl http://localhost:8000/v1/body/durov
```

Он отдаёт тот же API, что отдавало демо, со стартовой страницей, Swagger UI на
`/api` и этой документацией на `/docs/`. В разделе
[Быстрый старт](getting-started/quickstart.md) описано это и Docker Compose с
Valkey.

**Встройте его в своё приложение.** Запустите TelegramMe рядом с приложением,
в том же compose-проекте или поде, и дайте доступ к нему только своему
приложению: без опубликованного порта и публичного адреса. Приложение
обращается к нему по частной сети, как к любому внутреннему сервису. См.
[Docker Compose](deployment/compose.md).

**Масштабируйтесь на своих серверах.** Несколько серверов используют один
общий Redis; см. [Docker Compose](deployment/compose.md),
[Слой узлов](deployment/peers.md) и [Обратный прокси](deployment/reverse-proxy.md).

**Открывайте его в интернет только намеренно.** Если ваш экземпляр публичный,
включите [лимит запросов и proof of work](api/protection.md) и не отключайте
кэш. Тот, кто запускает экземпляр, отвечает за его трафик и за соблюдение
условий Telegram и закона (см. `NOTICE`).

**Переход с демо.** Замените базовый URL на адрес своего экземпляра. Пути,
параметры и ответы те же, потому что это тот же образ.
