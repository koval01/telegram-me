# Частые вопросы

**Нужен ли аккаунт Telegram или токен бота?**
Нет. Сервис читает те же публичные веб-страницы, которые браузер показывает по
адресу `t.me/s/<channel>`.

**Какие каналы поддерживаются?**
Публичные каналы с включённым веб-превью. Приватные каналы, группы,
пользователи и боты возвращаются как `404`.

**Доступны ли все посты?**
Всё, что показывает веб-превью. Часть контента Telegram там не показывает
(например, очень большие видео помечаются как `available: false`, а
комментарии не включаются).

**Насколько свежие данные?**
Не старше 10 с при значении по умолчанию `CACHE_MODE=normal` (120 с при
`aggressive`, в реальном времени при `off`). Превью кэшируются на час. См.
[Обзор API → Свежесть данных](api/index.md#freshness).

**Заблокирует ли Telegram мой сервер?**
При большом некэшированном трафике t.me может ограничить частоту запросов с IP
(ответы `503`). Не отключайте кэш, используйте Redis, если запускаете
несколько воркеров, держите `TELEGRAM_MAX_CONCURRENCY` на умеренном уровне и
ставьте перед публичными развёртываниями CDN или кэширующий прокси.

**Почему `/v1/feed` выключен?**
Ему нужна страница каждого канала из запроса, поэтому он намного дороже
остальных эндпоинтов. Включите его через `ENABLE_FEED=true`, желательно вместе
с Redis.

**Почему счётчики — строки?**
Они возвращаются ровно в том виде, в каком их форматирует Telegram (`10.3M`),
а это может терять точность; преобразование в числа создало бы видимость
точности, которой нет.

**Почему `text.entities[].offset` иногда удивляет?**
Смещения индексируют простую строку `string` так, как Python считает символы
(кодовые точки), а не в UTF-16 code units, как это делает Bot API Telegram.

**Я получаю `502`.**
Скорее всего, Telegram изменил разметку. Пожалуйста,
[создайте issue](https://github.com/koval01/telegram-me/issues) с URL.

**Я получаю `422` для существующего канала.**
Имена пользователей должны быть длиной 5–32 символа, начинаться с буквы и
содержать только буквы, цифры и `_`. Передавайте их без `@`.

**Можно ли запустить сервис без Docker?**
Да: `uv run telegram-me serve` (или `pip install .` и `telegram-me serve`).
