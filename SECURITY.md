# Security policy

## Supported versions

Only the latest release of telegram-me receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately instead:

- through GitHub: [report a vulnerability](https://github.com/koval01/telegram-me/security/advisories/new), or
- by email: [yaroslav@koval-dev.org](mailto:yaroslav@koval-dev.org).

Include what you found, how to reproduce it, the affected version or commit,
and its impact as you see it.

## What to expect

- An acknowledgement within 48 hours.
- Updates while the issue is investigated and fixed.
- Once a fix is released, a published advisory crediting you, unless you prefer
  to stay anonymous.

## Scope

This policy covers the code in this repository and the official Docker images
built from it. A vulnerability in a dependency should go to that project; tell
us too if telegram-me is affected.
